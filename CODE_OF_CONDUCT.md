# Code of Conduct

Be professional, specific, and respectful.

Contributors and maintainers are expected to:

- discuss code and behavior rather than attack people
- assume good intent while still reviewing critically
- provide reproducible technical feedback where possible
- avoid harassment, discrimination, threats, doxxing, and spam
- respect private security disclosures and confidential information

Maintainers may edit, hide, lock, or remove participation that materially disrupts the project, and may restrict repeat offenders from project spaces.

For conduct concerns involving a maintainer, use a private GitHub contact/reporting route where available rather than posting personal information publicly.
