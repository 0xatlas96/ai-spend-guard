# Governance

AI Spend Guard is currently maintained by **0xatlas96** as the primary maintainer.

## Decision making

- Small fixes and documentation improvements may be merged directly after review.
- Public API, security-model, persistence, and enforcement changes require explicit maintainer review.
- Backward-incompatible changes should include migration notes and normally wait for an appropriate release boundary.

## Maintainer responsibilities

The primary maintainer is responsible for issue triage, pull-request review, release management, security handling, and protecting the project's stated guarantees.

As sustained contributors emerge, maintainership can be expanded based on demonstrated technical judgment, review quality, security awareness, and consistent participation.
